# Python Test

Most similar test to the decentralized setup.

- How to run
  - Run ledger and services
  - Run guardian
  - generate user keys
  - Activate PDO client environment
  - Run `startup.py`
  - Run `stateless_test.py` (a policy graph, through the token and the guardian)
  - Run `policy_graph_test.py ../graphs/download/graph.json ../graphs/download/components
    ../graphs/download/graph_tests.json` (a graph policy, decided by its graph tests)
  - Run `cleanup.py`
